# AI-Powered Interview Preparation Platform

An AI-powered Interview Preparation Platform that generates role and company specific interview questions, evaluates candidate responses, analyzes facial expressions and body language, and provides detailed interview reports with performance tracking.

## Technologies Used

- Python
- Google Gemini API
- OpenAI Whisper
- MediaPipe Face Landmarker
- MediaPipe Pose Landmarker
- OpenCV
- MoviePy
- Gradio
- Matplotlib
- NumPy
- Pandas

## Features

- Company and role-specific interview question generation
- Speech-to-Text conversion using OpenAI Whisper
- AI-powered technical evaluation
- Facial expression analysis
- Body posture analysis
- Confidence and engagement score calculation
- Interview Score Dashboard
- Human Behaviour Analysis Report
- Final Interview Report
- Interview performance progress tracking

## Evaluation Parameters

### Technical Assessment

- Technical Score
- Communication Score
- Completeness Score

### Behaviour Assessment

- Face Visibility Score
- Head Alignment Score
- Eye Contact Score
- Smile Score
- Shoulder Alignment Score
- Head Position Score
- Posture Score
- Confidence Score
- Body Language Score
- Engagement Score

## Generated Reports

- Interview Score Dashboard
- Human Behaviour Analysis Report
- Final Interview Report
- Interview Performance Progress Graph
